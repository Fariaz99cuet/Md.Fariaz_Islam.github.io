Research Experience

Double-Barrier Exchange-Coupled-Composite MTJ Compact Model for BNN Accelerators
Ongoing
  • Proposed a novel DB-ECC-MTJ device architecture combining double-barrier STT enhancement with exchange-coupled-composite free layer optimization, achieving reduced switching current while keeping high thermal stability over conventional single-barrier MTJ at the 12 nm technology node.
  • Implemented a Verilog-A compact model in Cadence Virtuoso with interface-localized distributed spin-transfer torque, timer-based switching dynamics, and Brinkman tunneling resistance; demonstrated ΔE ≈ 60, Ic0 < 20 μA, device TMR ≈ 129%, and bidirectional switching within 1.5 ns at ±0.8 V in a 1T-1MTJ bitcell using gpdk090.
  • Currently extending the model to Deep Neural Network (DNN) inference accelerator design, leveraging the MTJ's inherent binary stochasticity and non-volatile weight storage for energy-efficient edge AI applications.
Hardware-Aware Bangla Vision-Language Model
2025
  • Hardware-Aware Bangla VLM Architecture: Designed a parameter-efficient vision-language model combining a frozen CLIP ViT-B/32 encoder, a novel Weighted Patch Aggregation (WPA) projector, and a LoRA-adapted Bangla LLM decoder, reducing trainable parameters to a small fraction of the full model while preserving captioning capability.
  • Implemented structured pruning-aware and quantization-aware fine-tuning via a straight-through estimator, so trainable weights adapt to reduced vision-tower capacity and INT8-rounded representations before deployment; applied post-training INT8 dynamic quantization to the language decoder for CPU inference.
  • Built a full hardware evaluation pipeline profiling parameter count, FLOPs, latency, throughput, and memory footprint across baseline/pruned/quantized configurations, achieving an estimated 60% reduction in model size and ~1.5× lower CPU inference latency via INT8 post-training quantization; evaluated captioning quality via BLEU, with a VQA extension underway for accuracy-based evaluation.
